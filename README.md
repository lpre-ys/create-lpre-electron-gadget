# create-electron-gadget

Scaffold a small Electron gadget app based on Vite + Vue.

## Usage

```bash
npm create lpre-electron-gadget@latest my-gadget
```

Or, from this repository without publishing:

```bash
node ./create-electron-gadget/bin/index.js my-gadget
```

Then:

```bash
cd my-gadget
npm install
npm run dev
```
